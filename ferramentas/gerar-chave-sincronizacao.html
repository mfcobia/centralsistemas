Chave da sincronização

Gera uma chave nova para a sincronização Monday → Gerador de Assinaturas. Tudo acontece neste navegador; nada é enviado para lugar nenhum.

  1. Clique em Gerar chave nova.
  2. No Supabase (projeto assinaturas): Edge Functions → sync-monday → Secrets, crie o segredo SYNC_KEY_HASH com o hash abaixo.
  3. No SQL Editor, rode o SQL de agendamento abaixo (ele já leva a chave).
  4. Confira no Manual da Central → SQL · Gerador → 04, bloco E, se a próxima sincronização respondeu sem erro.

A chave fica só dentro desse SQL. Não salve em arquivo, não mande por e-mail e não suba para o GitHub. Se perder, é só gerar outra.
